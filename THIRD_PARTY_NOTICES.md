## Docker image (docker/Dockerfile)

`COPY . /opt/network-xray` copies the whole repository, including everything listed above,
into the image (`.dockerignore` excludes only `.git`, `.github`, `.devcontainer`, backup files,
lab work dirs, `node_modules`, `package-lock.json`, internal `_*` files and the output of a local
run: `xray-states.js`, `problem.json`, `.xray.lock`). `LICENSE` and this file are copied too.

The image also contains software that is not in this repository and has its own licenses:

| Component | How it gets in | License |
|---|---|---|
| `node:24-alpine` base image (Node.js, Alpine Linux) | `FROM`, pinned by digest | unknown (not stated in this repository) |
| Alpine packages: bash, docker-cli, curl, ca-certificates, tini, coreutils, openssh-client | `apk add` | unknown (not stated in this repository) |
| containerlab binary, v0.82.0 | downloaded from the srl-labs/containerlab GitHub release, checked with a sha256 | unknown (not stated in this repository) |

The image's `org.opencontainers.image.licenses` label is `MIT`; it describes network-xray's
own code, not the base image, the packages, or the bundled NeXt UI / font / Tailwind files.

The demo images under `demo/compose-*/` (`node:24-alpine`, plus the Alpine `frr` package for the
collector) are built locally by `docker compose`; licenses not stated in this repository.

## Referenced, not bundled

These are pulled by name when a lab or the dev container runs. They are not in this
repository and are not redistributed by it:

- `frrouting/frr` (lab and demo routers, pinned by digest)
- `alpine` (lab hosts, pinned by digest)
- `vrnetlab/cisco_iol:17.18.02` (IOS-XE labs; no IOL image or binary is shipped, see README)
- `ghcr.io/srl-labs/containerlab/devcontainer-dind-slim:0.81.0` and the
  `ghcr.io/devcontainers/features/node` feature (`.devcontainer/devcontainer.json`)
- GitHub Actions in `.github/workflows/docker-image.yml`
